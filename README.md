# Home Assistant Apps

[![Repository zu Home Assistant hinzufügen](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FKeRegera%2Fha-usb-webcam)

## Apps

### [USB Webcam](./usb_webcam)

USB-Webcam (bis 4K, 30/60 fps, mit Ton) als normale Kamera-Entität in Home Assistant.

## Installation

1. **Einstellungen → Apps → App-Store** → ⋮ oben rechts → **Repositories**
2. `https://github.com/KeRegera/ha-usb-webcam` hinzufügen
3. **USB Webcam** installieren (wird auf deinem Gerät gebaut, dauert ein paar Minuten) und starten
