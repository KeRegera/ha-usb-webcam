# Home Assistant App: USB Webcam

USB-Webcam (bis 4K) als Kamera in Home Assistant – wie MotionEye, mit Datum/Uhrzeit im Bild.

![aarch64][aarch64-shield] ![amd64][amd64-shield]

- Kamera im Konfigurations-Tab aus einer Liste wählen
- Volle 4K auch auf dem Raspberry Pi
- Legt `camera.usb_webcam` automatisch an
